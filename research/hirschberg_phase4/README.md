# Hirschberg Phase 4 A: isolated research baseline

Noncommercial screening research only. Not a diagnosis or a replacement for an
eye examination. No production integration, patient-image acquisition or clinical
training has been performed. This first increment implements A0 infrastructure,
not the validated A1 detector or a four-class clinical screening system.

All output paths must be new. Writers refuse existing files/run directories.
Synthetic toy labels only exercise the software contract. Pseudo and normal have
the same geometric generating distribution intentionally: these features do not
establish a clinical distinction. Do not present smoke-test accuracy as evidence.
The synthetic `test` split is a fixture, not the future private clinical test.

Dependencies use the existing environment: numpy, scikit-learn, joblib and pytest.
No automatic installs/downloads. Metadata records environment versions and hashes;
this is not yet a fully pinned reproducible training environment. Load only trusted
local joblib artifacts because pickle deserialization can execute code.

## Data Contract

Manifest is a JSON list (see synthetic generator for an example). Required fields:
image_id, patient_id, source_id, source_kind, rights_status, split, label, width,
height, mirrored=false, coordinate_space=native, landmarks. Each OD/OS eye has
pupil, limbus and glint (native [x,y] or null) and limbus_diameter_px. The initial
feature extractor requires limbus/glint/diameter; pupil is a separate target and
is not substituted for limbus. Feature extraction does not load patient images.

Human records also require permission_record_id, consent_scope_id,
license_record_id and clinician_confirmed=true. These identifiers are review
references, not proof generated by software. A qualified reviewer must actually
verify the records; changing a flag is not consent. Unknown sources remain HOLD.
Synthetic/human training and evaluation are kept separate. All train/eval patients
must have one preselected record at this milestone. Real intermittent/indeterminate
targets need a reviewed clinical/image target policy before any import.
Keep human private-test records in a separate evaluator-only manifest; the trainer
rejects manifests containing them. Do not add private-test labels to development.

Patient/image/hash overlap across splits or against model training IDs is rejected.
Near-duplicate and real patient linkage review remains manual and mandatory.
Training uses only train rows, StandardScaler + fixed logistic regression;
evaluation never fits and includes a fifth confusion column for abstain.
Absent classes produce null macro recall, never fabricated results.

Only CSV text is read. Images remain untouched. Output keeps HOLD, no inferred
patient IDs, no clinical verification and legacy_crop coordinates. It is deliberately
not accepted by the trainer. Native images and genuine crop transforms must be
obtained lawfully before converting/reannotating to the native contract.
