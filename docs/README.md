# RemiCare Backend Documentation

Backend documentation is organized by purpose:

- `backend/`: architecture, model registry, database, governance, and readiness reports.
- `research/hirschberg/`: Hirschberg research audits, model cards, training plans, and data gap notes.
- existing Korean transfer and dataset research docs remain in this folder until their next cleanup pass.

Deployment-critical runtime files remain outside `docs/`, including `requirements.txt`, `runtime.txt`, `app/`, and model artifacts under `app/models/`.
