## Changes

Hirschberg now waits for the backend ping before submitting analysis. Cold-start
ping has a 90-second budget; the inference POST has a separate 60-second budget.
The previous 25-second override is absent from the deployed frontend bundle.
No inference/persistence POST is automatically retried.

The backend shares a single ONNX CPU session for the two image pipelines, uses
one CPU thread by default (configurable up to four), disables idle spinning,
preloads the Hirschberg artifacts, and executes measurements off the HTTP event
loop. Concurrent research measurements have one processing slot; requests that
cannot acquire it within two seconds receive a retryable HTTP 503 SERVER_BUSY.

Cover Test explicitly returns INCONCLUSIVE / MODEL_NOT_LOADED after saving raw
numeric data when no approved model exists. It does not generate probabilities,
confidence or a completed clinical prediction in that case. The frontend no
longer calls the retired Korean transfer endpoint as its fallback, nor invents
Korean model metadata or zero probabilities. Homepage data-handling copy reflects
server-side Hirschberg analysis and Cover Test numeric-data storage.
